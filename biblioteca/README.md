# Biblioteca de Tecnologias - Video Genius

Esta biblioteca contém documentação original e referências para as principais tecnologias utilizadas no projeto Video Genius.

## Tecnologias Documentadas

### 🚀 FastAPI
Framework web moderno e rápido para construção de APIs com Python.
- **Arquivos**: `README.md`, `exemplos/api_video.py`, `referencias.md`

### ☁️ Google Cloud Code
Extensão para desenvolvimento de aplicações nativas em nuvem.
- **Arquivos**: `README.md`, `configuracao.md`, `referencias.md`

### 📊 Google BigQuery
Data warehouse totalmente gerenciado e em escala de petabytes.
- **Arquivos**: `README.md`, `queries.md`, `exemplos.md`, `referencias.md`

### 🔄 Outras Tecnologias
- Google Cloud Storage
- Google Cloud Pub/Sub
- Google Cloud Tasks
- Google Secret Manager
- Uvicorn
- Pydantic
- Starlette
